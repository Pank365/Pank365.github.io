Project Overview

System Architecture

Multi-tier architecture showing the Angular client, Express API, and MongoDB database working together.

Travlr Getaways is a responsive multi-page travel website designed to help users explore vacation destinations, lodging, meals, news, and contact information through a clean and consistent user experience.

This project demonstrates front-end development, page organization, responsive design, navigation structure, and visual consistency across multiple webpages.

REST API Endpoints

  • GET /api/trips — Retrieve trips
  • POST /api/login — User authentication
  • POST /api/register — Register user
  • PUT /api/trips/:tripId — Update trip information
  • DELETE /api/trips/:tripId — Delete trip

Database Integration

MongoDB served as the application's database layer, storing trip information and supporting secure, persistent data management through RESTful API communication.
