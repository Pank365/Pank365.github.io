🚀 Building My First Full-Stack Application

Published July 2026

Travlr Getaways became much more than a school project. It was the first application that helped me understand how a modern software system works from end to end.

Working with Angular, Express.js, Node.js, MongoDB, REST APIs, JWT authentication, and responsive web design showed me how the frontend, backend, database, and security layers communicate to create a complete application.

Biggest Lesson

The biggest lesson was not learning one specific technology. It was understanding how all the parts connect.

A successful application is not simply a collection of good code. It is a set of components working together through clear architecture, reliable communication, careful testing, and thoughtful design.

Challenges I Worked Through

  • Connecting the Angular client to the Express REST API
  • Integrating MongoDB for persistent trip data
  • Implementing and testing JWT authentication
  • Protecting administrative routes and update operations
  • Debugging API requests, database responses, and interface behavior

What I Would Improve Next

  • Add automated unit and integration tests
  • Containerize the application with Docker
  • Create a continuous integration and deployment workflow
  • Improve accessibility and error messaging
  • Add role-based authorization for administrative users
